# Project Companion v0.2 — Bruno stories + local AI chat

## Install and run
1. Extract the ZIP to a **new folder** (do not overwrite your working v0.1 folder until you have a backup).
2. Open `project_companion_work` in VS Code, then run `npm install` and `npm run dev`.
3. Open **the same browser, hostname, and port** as before: `http://localhost:5173`.
4. Go to **Companion > Talk with Bruno**. Visual novel stories work immediately.

## Important: keeping your XP and tasks
The app uses the same localStorage key, `project-companion-v1`, and retains your existing tasks and XP. **Browser storage is scoped to the origin** (including port), not to the folder containing the code. Do not clear site data, use incognito, or change the port if you want your old progress to appear. Back up your data before switching: in your original app, press F12 > Console, enter `copy(localStorage.getItem('project-companion-v1'))`, then paste the copied JSON into a text file and save it privately. If `copy()` is unavailable, use `localStorage.getItem('project-companion-v1')` and copy the returned text. You can restore it in the browser Console using `localStorage.setItem('project-companion-v1', 'PASTE_JSON_HERE')`, carefully escaping quotes; a safer alternative is `localStorage.setItem('project-companion-v1', JSON.stringify(JSON.parse(\`PASTE_JSON_HERE\`)))` when JSON has no backticks. Reload after restoration. Chat history is also stored in the same browser storage key.

## Set up FREE local AI chat (optional)
1. Install Ollama from https://ollama.com/download/windows .
2. Open a separate terminal and run `ollama pull llama3.2:3b` (downloads a model; needs several GB of space).
3. Ensure Ollama is running. You can test with `ollama run llama3.2:3b`.
4. Keep the app running with `npm run dev` and visit Companion > AI free chat.
5. Vite proxies `/api/chat` to Ollama at `http://127.0.0.1:11434`, avoiding a browser API key and CORS configuration. The chat feature works only while your computer runs Ollama. It is not a cloud service and is not available on your phone unless you configure a secure server separately.

## Notes
- This is a personal, fan-made prototype, not an official JoJo app. The provided character art belongs to its respective rights holders.
- AI responses are generated by the local model, not official character dialogue or voice acting. Text-to-speech uses the browser's generic voice.
- Scripted visual novel conversations do not require Ollama or internet.
- Chat and story choices do **not** grant relationship XP; completing tasks remains the only XP source.
- Original Base44 files remain under `original-base44/` for reference.
